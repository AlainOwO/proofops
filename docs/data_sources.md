# Data sources and boundaries

- **FOCUS sample:** FOCUS-Sample-Data contributors, [original repository](https://github.com/FinOps-Open-Cost-and-Usage-Spec/FOCUS-Sample-Data), revision `adbdd17a132984d6e8583c149c236d2199c3f5bc`, `FOCUS-1.0/focus_sample.csv`, retrieved in the supplied research on 2026-10-05. Unmodified copy in `fixtures/billing/focus_sample.csv`. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), local license in [licenses/FOCUS-license.md](licenses/FOCUS-license.md). No endorsement implied. A 1,000-row multi-provider USD sample, not the demo service's bill.
- **Development knowledge cards, eight examples and answer schema:** original supplied ProofOps research. Source links are retained per card. Examples remain development material and never serve as held-out evaluation results.
- **Three shipped review replays:** original synthetic application fixtures generated by `scripts/generate_fixtures.py`. Prices, incidents, approvals and workload measurements are illustrative. No AWS run produced them.
- **RCAEval:** the research contains an MIT-licensed index and three controlled benchmark episodes. No RCAEval labels, index, fault-bearing paths or evaluator-only files are copied into the runtime. Optional diagnosis is deferred.
- **ITBench/Infracost research:** scenario/parser design references only; no upstream environment or Terraform has been executed. Infracost import is optional and deferred because the versioned rate-card path is implemented.

Research checksums are saved in `docs/research_checksums.json`; `python scripts/check_research.py` verifies the original files remain unchanged.

- **Workload script:** `testing/virtual_users.js` adapts the original supplied ProofOps research script. The app adds observed run accounting and explicit per-class results. Research originals remain unchanged; all local experiment outputs are labelled `local_observation`.
- **PDF typography:** embedded Bitstream Vera fonts are supplied by the locked ReportLab distribution. The redistribution notice is preserved in [licenses/bitstream-vera-license.txt](licenses/bitstream-vera-license.txt). Documentation diagrams are original vector drawings generated locally; no third-party screenshots or generated raster art are used.
- **UI icons:** Lucide React, locked in `frontend/package-lock.json`, supplies the interface icon components under its ISC license. Dependency license notices remain in the installed package; [Lucide license](https://lucide.dev/license).
